# project_autotest_disk
Автотесты для сервиса Яндекс Диска. 
Включает тесты, проверяющие работу методов GET, POST, PUT и DELETE
Стек: Java, Maven, JUnit, Rest Assured, Hamcrest.
Структура проекта включает в себя:
1. Класс TestConfig, который изолированно получает необходимые для тестирования данные.
2. Общий для всех тестовых классов Base Test.
3. Клиенты для методов.
4. Модели для обработки ссылок, статусов и ошибок.
5. Изолированные данные для адреса, тела запроса и схем ответов.
6. Спецификации для отправки запроса и обработки ответа.
7. Автотесты по разделам документации.
На данный момент проект включает в себя проверку разделов: Файлы и папки, Корзина, Асинхронная операция, Диск. Среди обработки ошибок включены: 400 и 401.
В дальнейшем планируется включение дополнительных тестов:
1. Обработка всех видов ответов.
2. Обработка всех ошибок.
3. Проверка нахождения созданных файлов в ответе.
4. Проверка необязательных параметров.
5. Тесты по разделу Публичные файлы и папки.
